
# ❄️ Frostly

### Find Your Cool. Save More.

Frostly is a Streamlit-based refrigerator marketplace designed to make buying second-hand refrigerators, exchanging old appliances, finding spare parts, and requesting repair services easier.

## 🚀 Features

- 🧊 **Refrigerator Catalogue** – Browse available refrigerators with product details, images, prices and filters.
- 🔄 **Exchange** – Explore options for exchanging old refrigerators.
- ⚙️ **Spare Parts** – Browse different refrigerator spare-part categories.
- 🔧 **Repair Services** – Explore refrigerator repair and maintenance services.
- 📞 **Contact** – Submit enquiries through a dedicated contact page.
- 🎨 **Modern UI** – Responsive, multi-page interface with custom styling and branding.

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/Frostly.git
```

### 2. Navigate to the project

```bash
cd Frostly
```

### 3. Create a virtual environment

```bash
python -m venv .venv
```

### 4. Activate the environment

Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the application

```bash
streamlit run app.py
```
